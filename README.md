# Big Data Pipelines on Google Cloud

## About the Course

This course introduces the fundamentals of big data and cloud-based data engineering using Google Cloud Platform (GCP). 

Learners will explore services such as 

1. Big Data Processing using Apache Spark

2. BigQuery

3. Dataflow

4. Dataproc

5. Pub/Sub, and 

6. Cloud Composer 

   to build and orchestrate batch and real-time data pipelines. Through practical examples, learners will understand how to ingest, process, validate, and manage large datasets efficiently.

**Objectives**

Learners will be able to design, optimize, and orchestrate efficient data pipelines for both batch and real-time processing, while ensuring data quality and cost-effectiveness by understanding and applying Google Cloud Platform (GCP) fundamentals and big data concepts, leveraging tools like Big Query, Dataflow, and Cloud Composer.

**Pre-Requisite:** Basic understanding of SQL and data processing concepts, with a general awareness of cloud computing
